# red5pro-coturn-installer
Use this script to install Coturn on a [Red5 Pro server](https://www.red5.net/red5-pro/low-latency-streaming-software/).

Syntax: `sudo ./r5coturninstall.sh FQDN or ip address`

See [this doc](https://www.red5.net/docs/red5-pro/users-guide/installation/archive/turn-stun/turnstun/) for instructions on configuring your server.
